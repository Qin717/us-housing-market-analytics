# Zillow Home Value Index Analysis (2000-01 – 2025-08)

## Overview
This project analyzes Zillow Home Value Index (ZHVI) data to understand housing market trends across different states and cities in the United States from January 2000 to August 2025.

## Data
- **Source**: Zillow Research Data
- **Raw Data**: `data/zillow_home_value_raw_data.csv` (Metro-level ZHVI data)
- **Processed Data**: `data/home_values_yearly_clean.csv` (Annual aggregated data)

## Analysis Questions
1. **Q1**: Top 10 States by Average Home Values
2. **Q2**: Top 5 States by Home Value Growth
3. **Q3**: Top 5 Cities by Growth (Absolute & Percentage)
4. **Q4**: Top 5 States with Highest Volatility
5. **Q5**: Housing Crisis Impact and Recovery Analysis
6. **Q6**: Regional Housing Value Trends in the U.S.
